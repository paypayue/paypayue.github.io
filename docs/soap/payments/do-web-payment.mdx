# <Translate id="soap.payments.doWebPayment.title">Pedido de pagamento com token (via redirect)</Translate>

<p><Translate id="soap.payments.doWebPayment.intro">De seguida apresentamos o processo de pagamento com redirecionamento para a página de pagamentos PayPay.</Translate></p>
* <Translate id="soap.payments.doWebPayment.step1">O servidor do site/aplicação comunica com a PayPay com o objetivo de obter um token de pagamento para a(s) forma(s) de pagamento pretendidas;</Translate>
* <Translate id="soap.payments.doWebPayment.step2">A PayPay responde com o</Translate> <code>redirectURL</code>, <code>paymentId</code> <Translate id="soap.payments.doWebPayment.step2b">e</Translate> <code>token</code>:
  * <Translate id="soap.payments.doWebPayment.step2a">O</Translate> <code>paymentId</code> <Translate id="soap.payments.doWebPayment.step2a2">e</Translate> <code>token</code> <Translate id="soap.payments.doWebPayment.step2a3">da resposta deverão ser guardados no servidor do site/aplicação;</Translate>
  * <Translate id="soap.payments.doWebPayment.step2b2">De seguida o site/aplicação deverá redirecionar o cliente para o</Translate> <code>redirectURL</code> <Translate id="soap.payments.doWebPayment.step2b3">da resposta;</Translate>
* <Translate id="soap.payments.doWebPayment.step3">Em caso de sucesso, o cliente será redirecionado para o</Translate> <code>returnUrlSuccess</code> <Translate id="soap.payments.doWebPayment.step3b">ou em caso de cancelamento para o</Translate> <code>returnUrlCancel</code>;
* <Translate id="soap.payments.doWebPayment.step4">O servidor do site/aplicação deverá verificar se o</Translate> <code>?token=XYZ</code> <Translate id="soap.payments.doWebPayment.step4b">do url de retorno é válido e verificar o estado do token para confirmar se o pagamento foi confirmado.</Translate> (<a href="../payments/check-web-payment">Ver checkWebPayment</a>);
* <Translate id="soap.payments.doWebPayment.step5">Se, por qualquer razão, o o cliente não regressar ao site/aplicação é recomendada a consulta ao estado do pagamento após um intervalo de referência de 30 minutos*.</Translate> (<a href="../payments/query-payments#checkentitypayments">Ver checkEntityPayments</a>)

\* <Translate id="soap.payments.doWebPayment.validityNote">A validade do pagamento é configurável por pedido no parâmetro</Translate> <code>validEndDate</code> <Translate id="soap.payments.doWebPayment.validityNote2">ou nas configurações da integração.</Translate>
### doWebPayment {#dowebpayment}

<Translate id="soap.payments.doWebPayment.description">Gera um token de pagamento via WEB para as formas de pagamento pretendidas.</Translate>
