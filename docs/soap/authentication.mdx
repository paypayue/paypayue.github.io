# <Translate id="soap.authentication.title">Autenticação</Translate>

<Translate id="soap.authentication.intro">O sistema verifica as credencias da plataforma integrada, é fornecida uma chave secreta para permitir realizar pedidos ao webservice. Para cada pedido do webservice deve ser enviada a seguinte hash de autenticação:</Translate>

<br/>
<br/>

```
sha256([Chave de encriptação] + [Data do pedido])
```
* <Translate id="soap.authentication.encryptionKey">Chave de encriptação - Chave privada da plataforma de integração.</Translate>
* <Translate id="soap.authentication.requestDate">Data do pedido - Formato da data ISO8601 (ex: 2014-09-27T18&colon;30&colon;49-03&colon;00).</Translate>

<Translate id="soap.authentication.hashValidity">A hash ficará inválida após a data do pedido ultrapassar a data-hora atual em 90 minutos.</Translate>
