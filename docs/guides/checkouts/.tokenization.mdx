# <Translate id="tokenization.title">Tokenização do método de pagamento</Translate>

<p><Translate id="tokenization.intro">A tokenização é o processo que permite armazenar os dados de pagamento confidenciais dos clientes de forma segura por meio da criação de um token.</Translate></p>

:::info
<Translate id="tokenization.availability">O armazenamento do método de pagamento apenas esta disponível para os</Translate> <strong>pagamentos</strong> <Translate id="tokenization.availability2">com</Translate> <strong>Cartão de Crédito/Débito e MB WAY</strong> <Translate id="tokenization.availability3">e no</Translate> <code>layout</code> <strong>basic</strong> <Translate id="tokenization.availability4">e</Translate> <strong>default</strong>.
:::

<p><Translate id="tokenization.steps">Para criar um token devem ser seguidos os seguintes passos:</Translate></p>

1. <Translate id="tokenization.step1">Obter o UUID do cliente;</Translate>
2. <Translate id="tokenization.step2">Compra através de checkout usando o id do cliente registado.</Translate>

### <Translate id="tokenization.getUuid.title">1. Obter o UUID do cliente</Translate>

<p><Translate id="tokenization.getUuid.description">O primeiro passo é obter o UUID do cliente que pretende registar o seu método de pagamento. Isso pode ser feito através de:</Translate></p>

- [<Translate id="tokenization.getUuid.createCustomer">Criar cliente</Translate>](/docs/guides/customers/create)
- [<Translate id="tokenization.getUuid.getCustomer">Consultar cliente</Translate>](/docs/guides/customers/get)
