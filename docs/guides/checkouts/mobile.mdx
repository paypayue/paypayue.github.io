# <Translate id="mobile.title">Incorporar em aplicação móvel</Translate>

<Translate id="mobile.intro">O checkout pode ser incorporado em aplicações móveis utilizando o componente</Translate> "Webview" <Translate id="mobile.intro2">e o mecanismo</Translate> "Deep linking" <Translate id="mobile.intro3">disponibilizado em Android e iOS.</Translate>

<p><Translate id="mobile.references">Referências úteis:</Translate></p>

- https://developer.android.com/training/app-links/deep-linking
- https://blog.devgenius.io/deep-linking-in-ios-f5bfa2959d0a
- https://en.yeeply.com/blog/deep-linking-android-ios-apps/

<p><Translate id="mobile.process">O processo funciona da seguinte forma:</Translate></p>

1. <Translate id="mobile.step1">(Back-end) Geração do link de checkout através do recurso /checkouts;</Translate>
2. <Translate id="mobile.step2">(Aplicação) Abrir o link obtido anteriormente em webview Android/iOS;</Translate>
3. <Translate id="mobile.step3">(Webview) Aguardar que o utilizador conclua o pagamento;</Translate>
4. <Translate id="mobile.step4">(Aplicação) Utilizador regressou à aplicação;</Translate>
5. <Translate id="mobile.step5">(Back-end) Consultar o estado do checkout via API;</Translate>
6. <Translate id="mobile.step6">(Aplicação) Apresentar a view da aplicação de acordo;</Translate>

### <Translate id="mobile.webview.title">Geração do link de checkout para Webview</Translate>

<Translate id="mobile.webview.description">O parâmetro</Translate> <code>redirects</code> <Translate id="mobile.webview.description2">do tipo</Translate> <code>action</code> <Translate id="mobile.webview.description3">deverá conter o url</Translate> "Deep link" <Translate id="mobile.webview.description4">irá invocar a aplicação após o pagamento.</Translate>
