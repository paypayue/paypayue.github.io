# <Translate id="checkouts.index.title">Início</Translate>

<Translate id="checkouts.index.intro">O recurso</Translate> <strong>Checkouts</strong> <Translate id="checkouts.index.intro2">permite criar uma página de pagamento de forma segura e personalizável, facilitando a maneira que solicita um pagamento.</Translate>
<Translate id="checkouts.index.features">Este recurso disponibiliza:</Translate>

<br/>
<br/>

- <Translate id="checkouts.index.feature1">Suporte para vários métodos de pagamento em simultâneo</Translate>;
- <Translate id="checkouts.index.feature2">Suporte para armazenar o método de pagamento e utiliza-lo em pagamentos futuros</Translate>;
- <Translate id="checkouts.index.feature3">Suporte para os idiomas Português, Inglês e Espanhol</Translate>;
- <Translate id="checkouts.index.feature4">Suporte para layouts diferentes de apresentação e adaptativos aos equipamentos</Translate>;
- <Translate id="checkouts.index.feature5">Redireccionamentos personalizáveis para o caso de sucesso no pagamento, cancelamento do pagamento e retrocesso na página de pagamento</Translate>;
- <Translate id="checkouts.index.feature6">Envio da informação do cliente, bem como do código e descrição do produto solicitado para pagamento</Translate>;
- <Translate id="checkouts.index.feature7">Validação do método de pagamento em tempo real, com mensagens de erros integradas</Translate>.

<Translate id="checkouts.index.additionalInfo">Este recurso possibilita o envio adicional das seguintes informações:</Translate>

<br/>
<br/>

- <Translate id="checkouts.index.customerData">Dados do cliente</Translate>;
- <Translate id="checkouts.index.billingAddress">Morada de cobrança</Translate>;
- <Translate id="checkouts.index.shippingAddress">Morada de expedição</Translate>.
