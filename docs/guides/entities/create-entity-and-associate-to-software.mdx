# Criar entidade e associá-la à integração

> Este recurso apenas está disponível para determinado tipo de integração.

Este recurso permite criar uma entidade na PayPay e que a mesma fique asssociada à integração que está a realizar o pedido. Permitindo assim, utilizar os mesmos dados de autenticação e necessitar apenas de alterar o header _PayPay-ClientId_ (NIF da entidade) para o da entidade associada e começar a realizar na respetiva entidade.

**Nota:** A criação da entidade através deste recurso seguirá todos os processos de compliance necessários.
