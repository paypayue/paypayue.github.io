A PayPay disponibiliza um ambiente de [testes](https://paypayue-dev.github.io/api) de forma a garantir a qualidade e a confiabilidade das integrações com a nossa solução.

# Requisitos

- Solicitar à nossa equipa de apoio um acesso ao ambiente de testes e as credenciais da API através do email [apoio@paypay.pt](mailto:apoio@paypay.pt)
- Indicar quais os métodos de pagamento que desejam testar.
- Se for pretendido realizar pagamentos através do MB WAY devem indicar os números de telemóveis desejados. São aceites números estrangeiros.

# Cartão de testes

Após a adesão e se pretenderem testar pagamentos com cartão é disponibilizado os dados de um cartão de testes.

# Multibanco

Caso seja pretendido colocar como pagas as referências multibanco é necessário indicar-nos quais e enviar para o email [apoio@paypay.pt](mailto:apoio@paypay.pt).
