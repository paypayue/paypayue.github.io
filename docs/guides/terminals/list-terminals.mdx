# <Translate id="terminals.listTerminals.title">Listar terminais</Translate>

<Translate id="terminals.listTerminals.intro">Obtenha a lista de todos os terminais associados à integração, com opções de filtro e paginação.</Translate>

<br/>

## <Translate id="terminals.listTerminals.searchParameters">Parâmetros de pesquisa</Translate>

<p><Translate id="terminals.listTerminals.parametersDescription">Todos os parâmetros são opcionais e podem ser combinados para refinar a pesquisa:</Translate></p>

| <Translate id="terminals.listTerminals.table.parameter">Parâmetro</Translate> | <Translate id="terminals.listTerminals.table.type">Tipo</Translate> | <Translate id="terminals.listTerminals.table.description">Descrição</Translate> | <Translate id="terminals.listTerminals.table.example">Exemplo</Translate> |
|-----------|------|-----------|---------|
| <code>terminalId</code> | string | <Translate id="terminals.listTerminals.param.terminalId">Filtrar pelo id do terminal</Translate> | <code>123456789</code> |
| <code>name</code> | string | <Translate id="terminals.listTerminals.param.name">Filtrar pelo nome do terminal</Translate> | <code>loja-centro</code>, <code>armazem-norte</code> |
| <code>page</code> | integer | <Translate id="terminals.listTerminals.param.page">Número da página (paginação)</Translate> | <code>1</code>, <code>2</code>, <code>3</code> |
| <code>limit</code> | string | <Translate id="terminals.listTerminals.param.limit">Número de resultados por página</Translate> | <code>10</code>, <code>25</code>, <code>50</code> (max: 500) |
| <code>sort</code> | string | <Translate id="terminals.listTerminals.param.sort">Ordenar resultados</Translate> | <code>createdAt</code>, <code>-created_at</code>, <code>terminalId</code> |

## <Translate id="terminals.listTerminals.responseStructure">Estrutura da Resposta</Translate>

| <Translate id="terminals.listTerminals.responseTable.field">Campo</Translate> | <Translate id="terminals.listTerminals.responseTable.type">Tipo</Translate> | <Translate id="terminals.listTerminals.responseTable.description">Descrição</Translate> |
|-------|------|-----------|
| <code>uuid</code> | string | <Translate id="terminals.listTerminals.field.uuid">Identificador único do terminal</Translate> |
| <code>terminalId</code> | string | <Translate id="terminals.listTerminals.field.terminalId">Id do terminal</Translate> |
| <code>name</code> | string | <Translate id="terminals.listTerminals.field.name">Nome do terminal</Translate> |
| <code>model</code> | string | <Translate id="terminals.listTerminals.field.model">Modelo do terminal</Translate> |
| <code>processor</code> | string | <Translate id="terminals.listTerminals.field.processor">Nome do processador das transações</Translate> |
| <code>supplier</code> | datetime | <Translate id="terminals.listTerminals.field.supplier">Nome do fornecedor do terminal</Translate> |
| <code>features.allowRemoteTransactions</code> | boolean | <Translate id="terminals.listTerminals.field.allowRemoteTransactions">Indica se o terminal aceita transações remotas (Suportado apenas em terminais cloud)</Translate> |

| <code>updatedAt</code> | datetime | <Translate id="terminals.listTerminals.field.updatedAt">Data da última atualização</Translate> |
