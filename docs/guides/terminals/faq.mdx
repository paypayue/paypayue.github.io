# <Translate id="terminals.faq.title">Perguntas Frequentes</Translate>

<p><Translate id="terminals.faq.intro">Encontre respostas rápidas para as dúvidas mais comuns sobre os terminais PayPay.</Translate></p>

### <Translate id="terminals.faq.q1">1. Quando é que os pagamentos passam para o estado "Confirmado"?</Translate>

<p><Translate id="terminals.faq.a1">Os pagamentos de terminais Verifone só passam para o estado</Translate> <strong><Translate id="terminals.faq.confirmed">Confirmado</Translate></strong> <Translate id="terminals.faq.a1b">após a PayPay receber o</Translate> <em>settlement</em> <Translate id="terminals.faq.a1c">com o estado de sucesso das operações.</Translate></p>

:::info
<Translate id="terminals.faq.settlementDescription">O settlement é o processo de liquidação financeira que confirma definitivamente a transação junto do banco adquirente.</Translate>
:::

### <Translate id="terminals.faq.q2">2. O que acontece se uma operação for realizada com sucesso num terminal Cloud e o webhook não chegar atempadamente à PayPay?</Translate>

<Translate id="terminals.faq.a2">O comportamento depende da data de validade do pagamento e das configurações enviadas:</Translate>

#### <Translate id="terminals.faq.scenario1">📋 Cenário 1: Data de validade ainda vigente</Translate>
- **<Translate id="terminals.faq.result">Resultado</Translate>:** <Translate id="terminals.faq.scenario1Result">O pagamento é aceite e transita para o estado</Translate> <strong><Translate id="terminals.faq.authorized">Autorizado</Translate></strong>.

#### <Translate id="terminals.faq.scenario2">📋 Cenário 2: Data de validade expirada, mas pagamento dentro do prazo</Translate>
- **<Translate id="terminals.faq.result">Resultado</Translate>:** <Translate id="terminals.faq.scenario2Result">O pagamento é aceite e fica no estado</Translate> <strong><Translate id="terminals.faq.authorizedCanceled">Autorizado (Cancelado)</Translate></strong>.

#### <Translate id="terminals.faq.scenario3">📋 Cenário 3: Data de validade expirada + flag</Translate> <code>blockLatePayment</code> <Translate id="terminals.faq.scenario3b">ativada</Translate>
- **<Translate id="terminals.faq.condition">Condição</Translate>:** <Translate id="terminals.faq.scenario3Condition">No pedido de solicitação do pagamento foi enviada a flag</Translate> <code>"validDate": {"{"}"blockLatePayment": true{"}"}</code>.
- **<Translate id="terminals.faq.result">Resultado</Translate>:** <Translate id="terminals.faq.scenario3Result">É feito o void do pagamento e fica no estado</Translate> <strong><Translate id="terminals.faq.canceled">Cancelado</Translate></strong>, <Translate id="terminals.faq.scenario3Result2">mesmo que a data do pagamento esteja dentro do prazo de validade.</Translate>

**<Translate id="terminals.faq.requestExample">Exemplo do pedido</Translate>:**
```json
{
  "amount": 100,
  "validDate": {
    "blockLatePayment": true
  }
}
```

#### <Translate id="terminals.faq.scenario4">📋 Cenário 4: Data de validade expirada e pagamento fora do prazo</Translate>
- **<Translate id="terminals.faq.result">Resultado</Translate>:** <Translate id="terminals.faq.scenario4Result">É feito o</Translate> <em>void</em> <Translate id="terminals.faq.scenario4Result2">do pagamento e fica no estado</Translate> <strong><Translate id="terminals.faq.canceled">Cancelado</Translate></strong>.

### <Translate id="terminals.faq.q3">3. Após um pagamento estar no estado "Settled", qual é o prazo máximo para realizar uma devolução?</Translate>

**<Translate id="terminals.faq.a3">Não existe período máximo</Translate>** <Translate id="terminals.faq.a3Description">para realizar devoluções de pagamentos no estado "Settled".</Translate>

:::info
<Translate id="terminals.faq.recommendationDescription">Não há um prazo máximo para processar devoluções, mas fazê-lo rapidamente contribui para uma gestão financeira mais eficaz e uma melhor experiência do cliente.</Translate>
:::
