### <Translate id="terminals.cloud.sendRefund.section1">1. Iniciação da Devolução (via API)</Translate>

<p><Translate id="terminals.cloud.sendRefund.section1Description">O seu sistema inicia a devolução remotamente através da API PayPay:</Translate></p>

1. <Translate id="terminals.cloud.sendRefund.step1">O sistema envia o pedido para API PayPay:</Translate>

##### <Translate id="terminals.cloud.sendRefund.endpoint">Endpoint</Translate>

```php
POST /terminals/{uuid}/refunds/{paymentId}
```

##### <Translate id="terminals.cloud.sendRefund.basicExample">Exemplo básico</Translate>
```json
{
  "amount": 100,
}
```

##### <Translate id="terminals.cloud.sendRefund.parameters">Parâmetros</Translate>

| <Translate id="terminals.cloud.sendRefund.table.parameter">Parâmetro</Translate> | <Translate id="terminals.cloud.sendRefund.table.type">Tipo</Translate> | <Translate id="terminals.cloud.sendRefund.table.required">Obrigatório</Translate> | <Translate id="terminals.cloud.sendRefund.table.description">Descrição</Translate> |
|-----------|------|-------------|-----------|
| <code>uuid</code> | string | ✅ <Translate id="terminals.cloud.sendRefund.yes">Sim</Translate> | <Translate id="terminals.cloud.sendRefund.param.uuid">UUID do terminal para o qual irá ser enviado o pedido de pagamento</Translate> |
| <code>paymentId</code> | string | ✅ <Translate id="terminals.cloud.sendRefund.yes">Sim</Translate> | <Translate id="terminals.cloud.sendRefund.param.paymentId">ID do pagamento PayPay que deseja devolver</Translate> |
| <code>amount</code> | integer | ✅ <Translate id="terminals.cloud.sendRefund.yes">Sim</Translate> | <Translate id="terminals.cloud.sendRefund.param.amount">Montante que deseja devolver</Translate> |


2. <Translate id="terminals.cloud.sendRefund.step2">API PayPay comunica com o terminal de forma</Translate> <strong>assíncrona</strong>;
3. <Translate id="terminals.cloud.sendRefund.step3">Terminal recebe e apresenta o valor automaticamente ao operador;</Translate>

:::info
<Translate id="terminals.cloud.sendRefund.waitTimeDescription">O terminal aguarda</Translate> <strong> <Translate id="terminals.cloud.sendRefund.oneMinute">1 minuto</Translate> </strong> <Translate id="terminals.cloud.sendRefund.waitTimeDescription2">pela apresentação do cartão.</Translate>

4. <Translate id="terminals.cloud.sendRefund.step4">API PayPay devolve a resposta do sucesso ou não do pedido assíncrono, enquanto o terminal aguarda pela apresentação do cartão.</Translate>

## <Translate id="terminals.cloud.sendRefund.terminalFlow">Fluxo de devolução no terminal</Translate>

<Translate id="terminals.cloud.sendRefund.terminalFlowDescription">Após o pedido de devolução ser enviado pela API, o processo no terminal segue estes passos:</Translate>

### <Translate id="terminals.cloud.sendRefund.section2">2. Apresentação do Cartão</Translate>

<p><Translate id="terminals.cloud.sendRefund.section2Description">O cliente apresenta o mesmo cartão usado no pagamento original:</Translate></p>

1. <Translate id="terminals.cloud.sendRefund.section2Step1">Terminal apresenta o valor da devolução ao operador;</Translate>
2. <Translate id="terminals.cloud.sendRefund.section2Step2">Cliente apresenta o cartão através de um dos métodos:</Translate>
   - **<Translate id="terminals.cloud.sendRefund.contactless">Contactless</Translate>**: <Translate id="terminals.cloud.sendRefund.contactlessDescription">Aproxima cartão ou dispositivo móvel.</Translate>
   - **<Translate id="terminals.cloud.sendRefund.chip">Chip</Translate>**: <Translate id="terminals.cloud.sendRefund.chipDescription">Insere cartão no terminal.</Translate>
   - **<Translate id="terminals.cloud.sendRefund.magnetic">Banda magnética</Translate>**: <Translate id="terminals.cloud.sendRefund.magneticDescription">Passa o cartão.</Translate>
3. <Translate id="terminals.cloud.sendRefund.section2Step3">Terminal valida se o cartão corresponde ao pagamento original.</Translate>

:::warning
<Translate id="terminals.cloud.sendRefund.cardValidationDescription">O cartão deve ser o</Translate> <strong><Translate id="terminals.cloud.sendRefund.sameCardUsed">mesmo utilizado no pagamento original</Translate></strong>. <Translate id="terminals.cloud.sendRefund.cardValidationDescription2">Se for apresentado um cartão diferente, a devolução será recusada.</Translate>
:::

### <Translate id="terminals.cloud.sendRefund.section3">3. Autenticação</Translate>

<p><Translate id="terminals.cloud.sendRefund.section3Description">Dependendo do valor e tipo de cartão, pode ser necessária autenticação:</Translate></p>

1. <Translate id="terminals.cloud.sendRefund.section3Step1">Dados do cartão são lidos e validados pelo terminal;</Translate>
2. <Translate id="terminals.cloud.sendRefund.section3Step2">Sistema verifica se autenticação é necessária:</Translate>
   - **<Translate id="terminals.cloud.sendRefund.ifYes">Se sim</Translate>**: <Translate id="terminals.cloud.sendRefund.enterPin">Cliente introduz PIN.</Translate>
     - <Translate id="terminals.cloud.sendRefund.correctPin">Se PIN correto: Prossegue para processamento.</Translate>
     - <Translate id="terminals.cloud.sendRefund.incorrectPin">Se PIN incorreto: Nova tentativa ou cancelamento (máx. 3 tentativas).</Translate>
   - **<Translate id="terminals.cloud.sendRefund.ifNo">Se não</Translate>**: <Translate id="terminals.cloud.sendRefund.directProcessing">Processamento direto para autorização.</Translate>

**<Translate id="terminals.cloud.sendRefund.authTypes">Tipos de autenticação:</Translate>**
- **PIN**: <Translate id="terminals.cloud.sendRefund.pinDescription">Normalmente requerido para devoluções.</Translate>
- **<Translate id="terminals.cloud.sendRefund.noAuth">Sem autenticação</Translate>**: <Translate id="terminals.cloud.sendRefund.noAuthDescription">Em alguns casos de valores reduzidos.</Translate>

### <Translate id="terminals.cloud.sendRefund.section4">4. Processamento e Confirmação</Translate>

<p><Translate id="terminals.cloud.sendRefund.section4Description">O terminal comunica com a rede de pagamentos para processar a devolução:</Translate></p>

1. <Translate id="terminals.cloud.sendRefund.section4Step1">Terminal valida dados e envia pedido para rede de pagamento;</Translate>
2. <Translate id="terminals.cloud.sendRefund.section4Step2">Rede contacta banco emissor para processar devolução;</Translate>
3. <Translate id="terminals.cloud.sendRefund.section4Step3">Resposta é enviada de volta ao terminal:</Translate>
   - **<Translate id="terminals.cloud.sendRefund.approved">Aprovada</Translate>**: <Translate id="terminals.cloud.sendRefund.approvedDescription">Devolução processada com sucesso.</Translate>
   - **<Translate id="terminals.cloud.sendRefund.declined">Recusada</Translate>**: <Translate id="terminals.cloud.sendRefund.declinedDescription">Mensagem de erro apresentada.</Translate>

### <Translate id="terminals.cloud.sendRefund.section5">5. Notificação ao Sistema</Translate>

<Translate id="terminals.cloud.sendRefund.section5Description">Após a confirmação, o seu sistema é notificado:</Translate>

1. <Translate id="terminals.cloud.sendRefund.section5Step1">A Transação é sincronizada com backoffice PayPay em tempo real;</Translate>
2. <Translate id="terminals.cloud.sendRefund.section5Step2">A PayPay notifica via</Translate> <strong>Webhook</strong> <Translate id="terminals.cloud.sendRefund.section5Step2b">o seu sistema com detalhes da devolução.</Translate>

:::tip
<Translate id="terminals.cloud.sendRefund.webhookEssentialDescription">Configure webhooks para receber notificações automáticas do resultado da devolução. A resposta da API indica apenas que o pedido foi enviado ao terminal, não o resultado final.</Translate>
:::
