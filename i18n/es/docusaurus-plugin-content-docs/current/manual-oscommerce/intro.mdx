# osCommerce

## [Download](https://apps.oscommerce.com/Apps&JHMvS&paypay-oscommerce)

## Requisitos

- PHP 5.4
- osCommerce 2.3.2
- [SOAP extension](http://php.net/manual/en/book.soap.php)

Una vez finalizada la instalación y configurada la tienda, vaya al área de administración e inicie sesión.
