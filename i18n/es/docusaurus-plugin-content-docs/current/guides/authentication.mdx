# <Translate id="guides.authentication.title">Autenticação</Translate>

<p><Translate id="guides.authentication.intro">O sistema verifica as credencias da plataforma integrada, de forma a autenticar deverá indicar os seguintes elementos em cada pedido:</Translate></p>

  - <Translate id="guides.authentication.username">Username: Platform Code</Translate>
  - <Translate id="guides.authentication.password">Password: Private Key</Translate>

- `<clientId>` - <Translate id="guides.authentication.clientId">NIF da entidade</Translate>
