# <Translate id="terminals.cloud.index.title">Início</Translate>

<p><Translate id="terminals.cloud.index.intro">O Terminal Cloud é uma solução avançada que permite integração completa entre o terminal de pagamento e o sistema do cliente através de API REST, possibilitando automação e controlo remoto das transações.</Translate></p>
