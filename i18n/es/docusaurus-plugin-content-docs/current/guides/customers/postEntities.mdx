# <Translate id="customers.postEntities.title">Associar o cliente a outras entidades</Translate>

:::info
<Translate id="customers.postEntities.noteDescription">A associação do cliente, apenas pode ser realizada pela entidade que o criou.</Translate>
:::

<p><Translate id="customers.postEntities.intro">A associação de um cliente a outras entidades, permite que o registo do cliente fique disponível nas entidades desejadas.</Translate></p>

<Translate id="customers.postEntities.requirement">Para realizar essa associação é necessário conhecer o</Translate> <em>uuid</em> <Translate id="customers.postEntities.requirement2">do cliente e o</Translate> <em>clientId</em> <Translate id="customers.postEntities.requirement3">das entidades.</Translate>

<br/>
<br/>

<Translate id="customers.postEntities.example">Associar o cliente com o</Translate> <em>uuid</em> e2343605-cf46-43de-b20b-9b7d1c95a9b2 <Translate id="customers.postEntities.example2">a entidade com o</Translate> <em>clientId</em> 523308191 e 559514166
