PayPay proporciona un [entorno de pruebas](https://paypayue-dev.github.io/api) para garantizar la calidad y fiabilidad de las integraciones con nuestra solución.

# Requisitos

- Solicitar a nuestro equipo de asistencia el acceso al entorno de prueba y las credenciales de la API enviando un correo electrónico a [apoio@paypay.pt](mailto:apoio@paypay.pt)
- Indicar los métodos de pago que desean probar.
- Si desea realizar pagos a través de MB WAY, deberán indicar los números de teléfono móvil que desea utilizar. Se aceptan números extranjeros.

# Tarjeta de prueba

Tras registrarse y si desea probar los pagos con tarjeta, se le facilitarán los datos de una tarjeta de prueba.

# Cajero Automático

Si desea colocar las referencias del cajero automático como pagadas, háganoslo saber enviando un correo electrónico a [apoio@paypay.pt](mailto:apoio@paypay.pt)
