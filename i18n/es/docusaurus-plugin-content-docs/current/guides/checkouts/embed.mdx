# <Translate id="embed.webpage">Incorporar na página web</Translate>

<p><Translate id="embed.intro">Para obter o link da incorporação é necessário realizar um pedido POST /checkouts com os dados pretendidos.</Translate></p>

<Translate id="embed.redirectParam">O parâmetro</Translate> <code>redirects</code> <Translate id="embed.redirectParam2">do tipo</Translate> <code>action</code> <Translate id="embed.redirectParam3">é obrigatório e deverá conter o url para onde o cliente deve ser redireccionado após o processamento do pagamento.</Translate>
<Translate id="embed.checkoutId">O parâmetro id do checkout é automaticamente concatenado ao url no momento do redireccionamento.</Translate>

<br/>
<br/>

```json
{
	...

	"redirects": [
		{
			"type": "action", // <== Redireccionamento obrigatório
			"url": "https://www.url-action.dominio"
		}
	]
}
```

<p><Translate id="embed.htmlInstructions">Para criar o formulário de pagamento basta adicionar as seguintes linhas HTML/JavaScript à sua página.</Translate>
<Translate id="embed.idReplacement">O</Translate> <code>{'{id}'}</code> <Translate id="embed.idReplacement2">deve ser substituído pelo id retornado na resposta do pedido,no exemplo anterior seria o 0uJQvNoxoloZCn4gyuGKIWR8dtU9OnAm0emxYWcb.</Translate></p>

```html

```
