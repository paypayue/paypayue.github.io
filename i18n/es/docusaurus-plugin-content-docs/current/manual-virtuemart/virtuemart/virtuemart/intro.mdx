# Requisitos

<a href="https://paypay.pt/paypay/public/plugins/prestashop-plugins.zip" target="_blank" className="btn-download">Descargar</a>

Para instalar la extensión con PayPay:
- El comerciante deberá estar registrado en la plataforma PayPay;
- Debe descargar la versión 3.7.5 de Joomla, disponible en
    https://downloads.joomla.org/;
- Instalar el plugin VirtueMart, versión 3.2.x en su ordenador, disponible en
    https://virtuemart.net;
- Una vez completada la instalación y configurada la tienda, acceda al área de administración e inicie sesión.
