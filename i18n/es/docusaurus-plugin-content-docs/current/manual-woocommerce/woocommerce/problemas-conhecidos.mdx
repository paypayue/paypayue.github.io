# Problemas detectados

## Diseño basado en bloques en la página de pago (checkout) de WooCommerce

El plugin WooCommerce de PayPay no es compatible con el diseño de pago en bloque. Si está utilizando este tipo de diseño, los métodos de pago no se mostrarán en la página de pago. Deberá cambiar la sección de checkout para utilizar el modo de checkout clásico. Para ello, siga los siguientes pasos:

1. En la página de administración de WordPress, busque la página de checkout y haga clic en ‘Editar’.

![problemas1](../../../../../../_media/woocomerce-22.png)

2. Después de editar la página, seleccione el bloque asociado a los métodos de pago.

![problemas2](../../../../../../_media/woocomerce-23.png)

3. Si la página de checkout está utilizando el diseño de checkout en bloque, aparecerá una advertencia en el panel derecho de la página de edición. Haga clic en ‘Actualizar’ para que se guarden los cambios. Los métodos de pago deberían aparecer ahora al realizar el pago.

![problemas3](../../../../../../_media/woocomerce-24.png)

## Almacenamiento de pedidos de alto rendimiento

El plugin WooCommerce de PayPay no es compatible con el almacenamiento de pedidos de alto rendimiento. Si utiliza este tipo de almacenamiento, deberá cambiar a ‘WordPress posts storage (legacy)’ y guardar los cambios.

![problemas4](../../../../../../_media/woocomerce-25.png)
