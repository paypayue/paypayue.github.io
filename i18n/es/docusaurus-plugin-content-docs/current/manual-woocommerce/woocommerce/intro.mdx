# Requisitos

<a href="https://wordpress.org/plugins/paypay-pagamentos-multibanco-e-cartao-de-creditodebito/" target="_blank" className="btn-download">Descargar</a>

Para efectuar la integración con PayPay, el comerciante deberá:
- Estar registrado en la plataforma PayPay;
- Descargar la versión 4.7.3 de WordPress, disponible en
    https://wordpress.org/download/;
- Instalar el plugin de WooCommerce en su ordenador, disponible en
    https://paypay.pt/paypay/public/plugins/paypay-woocommerce.zip;
- Una vez finalizada la instalación y configurada la tienda, ir al área de administración e iniciar sesión.
