## <Translate id="integrations.woocommerce.knownIssues.blockLayout">Layout baseado em blocos na página de checkout WooCommerce</Translate>

<Translate id="integrations.woocommerce.knownIssues.blockLayoutDescription">O plugin WooCommerce da PayPay não oferece suporte ao layout de checkout em blocos. Se estiver utilizando este tipo de layout, as formas de pagamento não serão apresentadas na página de checkout. É necessário alterar a seção de checkout para usar o modo de checkout clássico. Para fazer isso, siga as etapas abaixo:</Translate>

<br/>
<br/>

1. <Translate id="integrations.woocommerce.knownIssues.blockLayoutStep1">Na página de administração do WordPress, encontre a página de checkout e cliqueem editar.</Translate>

![problemas1](@site/_media/woocommerce-22.png)

2. <Translate id="integrations.woocommerce.knownIssues.blockLayoutStep2">Após ser apresentada a edição da página é necessário selecionar o bloco associado as formas de pagamento.</Translate>

![problemas2](@site/_media/woocommerce-23.png)

3. <Translate id="integrations.woocommerce.knownIssues.blockLayoutStep3">Caso a página de checkout estiver utilizando o layout de checkout em blocos, aparecerá um aviso no painel direito da página de edição. Clique em "Mudar para layout clássico" e depois clique em "Atualizar" para que as alterações sejam guardadas. Agora já deverá aparecer as formas de pagamento ao realizar um checkout.</Translate>

![problemas3](@site/_media/woocommerce-24.png)
