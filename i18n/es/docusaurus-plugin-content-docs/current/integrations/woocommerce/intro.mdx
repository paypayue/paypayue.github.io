Para efectuar la integración con PayPay, el comerciante deberá:
- Estar registrado en la plataforma PayPay;
- Descargar [WordPress](https://wordpress.org/download/);
- Instalar el plugin de [WooCommerce](https://wordpress.org/plugins/woocommerce/);
- Una vez finalizada la instalación y configurada la tienda, ir al área de administración e iniciar sesión.
