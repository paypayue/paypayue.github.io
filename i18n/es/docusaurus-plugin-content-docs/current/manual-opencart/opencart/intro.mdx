# Requisitos

<a href="https://www.opencart.com/index.php?route=marketplace/extension/info&extension_id=27224" target="_blank" className="btn-download">Descargar</a>

Para efectuar la integración con PayPay, el comerciante deberá:
- Estar registrado en la plataforma PayPay;
- Instalar OpenCart en su ordenador, desde www.opencart.com;
- Descargar los ficheros para el plugin OpenCart en https://www.paypay.pt;
- Configurar la información, con la moneda ‘Euro’ y el país ‘Portugal’ (your-storeurl/admin/index.php) y en Settings > Edit your store > Local;

![requisitos1](../../../../../../_media/opencart-1.png)
