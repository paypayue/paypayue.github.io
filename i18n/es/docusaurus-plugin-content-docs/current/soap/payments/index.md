# Geração de dados de pagamento

O método disponibilizado de seguida foram idealizados para os seguintes cenários:
* Geração de referências Multibanco com validade (Ex: para incluir em documentos, páginas WEB ou email);
* Geração de link de pagamento com várias formas de pagamento (Ex: para envio para o cliente por email, disponibilização em página WEB);
* Geração de referência pagável através da página inicial da PayPay.
