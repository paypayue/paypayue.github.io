PayPay provides a [test environment](https://paypayue-dev.github.io/api) to ensure the quality and reliability of integrations with our solution.

# Requirements

- Request access to the test environment and API credentials from our support team by sending an email to [apoio@paypay.pt](mailto:apoio@paypay.pt)
- Indicate the payment methods you want to test.
- If you want to make payments via MB WAY, you will need to indicate the mobile phone numbers you want to use. Foreign numbers are accepted.

# Test Card

After registration and if you want to test card payments, you will be provided with the details of a test card.

# ATM

If you want to place the ATM references as paid, please let us know by sending an email to [apoio@paypay.pt](mailto:apoio@paypay.pt).
