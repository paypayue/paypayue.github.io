# <Translate id="webhooks.requestAuth.title">Autenticação das notificações</Translate>

<p><Translate id="webhooks.requestAuth.intro">O seguinte header é enviado no pedido HTTP de forma a permitir verificar a sua integridade e autenticidade:</Translate></p>

```
PayPay-Signature: hash=14d06cc11e0479c2ffe138d963462bc0f0ad94e8e006cf4f1f494c5e30bd1830,ts=1615826436
```

<Translate id="webhooks.requestAuth.verification">O header é composto pela assinatura</Translate> <code>hash</code> <Translate id="webhooks.requestAuth.verification2">e o timestamp</Translate> <code>ts</code>. <Translate id="webhooks.requestAuth.verification3">Para verificar se o pedido é válido a seguinte hash deverá ser igual à</Translate> <code>hash</code> <Translate id="webhooks.requestAuth.verification4">do header:</Translate>

```php
hash_hmac("SHA256", [payload] + [ts], [Password/Private Key])
```

<Translate id="webhooks.requestAuth.example">Exemplo de uma função em PHP para validação da assinatura</Translate>

```php
private function has_valid_signature( $private_key ) {
    if (!isset($_SERVER['HTTP_PAYPAY_SIGNATURE'])) {
        return false;
    }

    $body = file_get_contents('php://input');

    $signature = str_replace(',', '&', $_SERVER['HTTP_PAYPAY_SIGNATURE']);

    parse_str($signature, $output);

    return (int) ($output['ts'] ) > (time() - 1800 ) &&
        hash_equals($output['hash'], hash_hmac('sha256', $body . $output['ts'], $private_key));
}
```
