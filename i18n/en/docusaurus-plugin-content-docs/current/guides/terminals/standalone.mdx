<Translate id="terminals.standalone.intro">O Terminal Standalone da PayPay é uma solução autónoma que permite aceitar pagamentos com cartão de forma simples e rápida, sem necessidade de integração técnica complexa.</Translate>

<br/>

## <Translate id="terminals.standalone.architecture">Arquitetura da Integração</Translate>

<p><Translate id="terminals.standalone.architectureDescription">O Terminal Standalone funciona de forma autónoma com sincronização automática para o backoffice da PayPay. Opcionalmente, pode integrar-se com sistemas externos através de webhooks.</Translate></p>
