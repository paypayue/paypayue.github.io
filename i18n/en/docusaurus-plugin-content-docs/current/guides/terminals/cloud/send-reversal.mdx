## <Translate id="terminals.cloud.sendReversal.whatIsReversal">O que é uma Reversão?</Translate>

<p><Translate id="terminals.cloud.sendReversal.whatIsReversalDescription">Uma reversão (reversal) cancela uma transação que ainda não foi liquidada (settled). Ao contrário de uma devolução, a reversão impede que os fundos sejam transferidos, cancelando a autorização antes do settlement.</Translate></p>

:::warning
<Translate id="terminals.cloud.sendReversal.timeLimit">A reversão só pode ser efetuada antes do settlement diário. Após o settlement, deve utilizar uma devolução (refund).</Translate>
:::

## <Translate id="terminals.cloud.sendReversal.processing">Processamento da Reversão</Translate>

<Translate id="terminals.cloud.sendReversal.processingDescription">Após o pedido de reversão ser enviado pela API, o processo segue estes passos:</Translate>

1. <Translate id="terminals.cloud.sendReversal.section2Step1">Terminal recebe o pedido de reversão;</Translate>
2. <Translate id="terminals.cloud.sendReversal.section2Step2">Sistema envia pedido de cancelamento para a rede de pagamentos;</Translate>
3. <Translate id="terminals.cloud.sendReversal.section2Step3">Rede contacta banco emissor para cancelar a autorização;</Translate>
4. <Translate id="terminals.cloud.sendReversal.section2Step4">Resposta é enviada de volta ao terminal:</Translate>
   - **<Translate id="terminals.cloud.sendReversal.approved">Aprovada</Translate>**: <Translate id="terminals.cloud.sendReversal.approvedDescription">Reversão processada com sucesso, autorização cancelada.</Translate>
   - **<Translate id="terminals.cloud.sendReversal.declined">Recusada</Translate>**: <Translate id="terminals.cloud.sendReversal.declinedDescription">Mensagem de erro apresentada (ex: pagamento já liquidado).</Translate>

:::info
<Translate id="terminals.cloud.sendReversal.noCardRequired">A reversão não requer a apresentação do cartão, uma vez que é um cancelamento da autorização original.</Translate>
:::

### <Translate id="terminals.cloud.sendReversal.section3">3. Notificação ao Sistema</Translate>

<Translate id="terminals.cloud.sendReversal.section3Description">Após a confirmação, o seu sistema é notificado:</Translate>

1. <Translate id="terminals.cloud.sendReversal.section3Step1">A Transação é sincronizada com backoffice PayPay em tempo real;</Translate>
2. <Translate id="terminals.cloud.sendReversal.section3Step2">A PayPay notifica via</Translate> <strong>Webhook</strong> <Translate id="terminals.cloud.sendReversal.section3Step2b">o seu sistema com detalhes da reversão.</Translate>
