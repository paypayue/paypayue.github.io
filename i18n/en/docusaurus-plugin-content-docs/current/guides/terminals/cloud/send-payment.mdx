<p><Translate id="terminals.cloud.sendPayment.section1Description">O seu sistema inicia o pagamento remotamente através da API PayPay:</Translate></p>

1. <Translate id="terminals.cloud.sendPayment.step1">O sistema envia o pedido para API PayPay:</Translate>

##### <Translate id="terminals.cloud.sendPayment.endpoint">Endpoint</Translate>

```php
POST /terminals/{uuid}/payments
```

##### <Translate id="terminals.cloud.sendPayment.basicExample">Exemplo básico</Translate>
```json
{
  "amount": 100,
  "code": "sale-code",
  "summary": "sale-description"
}
```

##### <Translate id="terminals.cloud.sendPayment.parameters">Parâmetros</Translate>

| <Translate id="terminals.cloud.sendPayment.table.parameter">Parâmetro</Translate> | <Translate id="terminals.cloud.sendPayment.table.type">Tipo</Translate> | <Translate id="terminals.cloud.sendPayment.table.required">Obrigatório</Translate> | <Translate id="terminals.cloud.sendPayment.table.description">Descrição</Translate> |
|-----------|------|-------------|-----------|
| <code>uuid</code> | string | ✅ <Translate id="terminals.cloud.sendPayment.yes">Sim</Translate> | <Translate id="terminals.cloud.sendPayment.param.uuid">UUID do terminal para o qual irá ser enviado o pedido de pagamento</Translate> |
| <code>amount</code> | integer | ✅ <Translate id="terminals.cloud.sendPayment.yes">Sim</Translate> | <Translate id="terminals.cloud.sendPayment.param.amount">Montante</Translate> |
| <code>code</code> | string | ❌ <Translate id="terminals.cloud.sendPayment.no">Não</Translate> | <Translate id="terminals.cloud.sendPayment.param.code">Código indicado pelo comerciante, por exemplo, código da encomenda do sistema</Translate> |
| <code>summary</code> | string | ❌ <Translate id="terminals.cloud.sendPayment.no">Não</Translate> | <Translate id="terminals.cloud.sendPayment.param.summary">Descrição indicado pelo comerciante, por exemplo, descrição da encomenda do sistema</Translate> |


2. <Translate id="terminals.cloud.sendPayment.step2">API PayPay comunica com o terminal de forma</Translate> <strong>assíncrona</strong>;
3. <Translate id="terminals.cloud.sendPayment.step3">Terminal recebe e apresenta o valor automaticamente ao operador;</Translate>

:::info
<Translate id="terminals.cloud.sendPayment.waitTimeDescription">O terminal aguarda</Translate> <strong> <Translate id="terminals.cloud.sendPayment.oneMinute">1 minuto</Translate> </strong> <Translate id="terminals.cloud.sendPayment.waitTimeDescription2">pela apresentação do cartão.</Translate>
:::
