Copy the files provided by PayPay into the WordPress plugins folder.

![configuracao1](../../../../../../_media/woocomerce-2.png)

:::info

In case there are other payment modules installed, you should make sure that there are no files overlapping the existing one.

:::

In the administration/backoffice environment of your e-commerce shop, go to the ‘Plugins’ menu and select the option ‘Installed Plugins’.

![configuracao2](../../../../../../_media/woocomerce-3.png)

In this area you can see the PayPay payment module (ATM -Multibanco-, Credit/Debit Card and MB WAY). Activate the PayPay plugin.

![configuracao3](../../../../../../_media/woocomerce-4.png)

Click on the ‘Settings’ option and fill in the fields with the PayPay details, which you can get from ‘Configuration’ > ‘Integrations’ > ‘Integration Platforms’ > ‘Add’ (WooCommerce Extension), and at the end, select the option ‘Save Changes’.

![configuracao4](../../../../../../_media/woocomerce-5.png)
