In order to execute the integration with PayPay, the merchant:
- Must be registered on the PayPay platform;
- Must download WordPress version 4.7.3, available at
https://wordpress.org/download/;
- Must install the WooCommerce plugin on his/her computer, available at
https://paypay.pt/paypay/public/plugins/paypay-woocommerce.zip;
- Once the installation is complete and the shop is configured, go to the administration area and log in.
