# Requirements

<a href="https://paypay.pt/paypay/public/plugins/prestashop-plugins.zip" target="_blank" className="btn-api btn-api--float-right">Descarregar</a>

To install the PayPay extension, the merchant:
- Must be registered on the PayPay platform;
- Must download Joomla version 3.7.5, available at https://downloads.joomla.org/;
- Install the VirtueMart plugin, version 3.2.x on his/her computer, available at
    https://virtuemart.net;
- Once the installation is complete and the shop is configured, access the administration area and log in.
