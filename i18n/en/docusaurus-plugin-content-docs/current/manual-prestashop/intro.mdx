# PrestaShop

## [Download](https://paypay.pt/paypay/public/plugins/prestashop-plugins.zip)

## Requirements

In order to execute the integration with PayPay, the merchant:
- Must be registered on the PayPay platform;
- Must have a PrestaShop online shop:
    https://www.prestashop.com/pt/;
- Must download the zipped folders from https://paypay.pt from Prestashop and save them on his/her computer;
- Access the administration environment of his/her e-commerce platform.
