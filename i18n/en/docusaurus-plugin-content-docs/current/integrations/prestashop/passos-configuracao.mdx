import Translate from '@docusaurus/Translate';

<Translate id="integrations.prestashop.config.intro">Ao descarregar a pasta zipada, deverá extrair os ficheiros zip. De seguida, realizar os próximos passos para cada módulo que pretenda instalar.</Translate>

<br/>
<br/>

![conteudo zip prestashop](@site/_media/prestashop/prestashop-1.png)

<Translate id="integrations.prestashop.config.step1">No ambiente de administração/backoffice da sua loja de e-commerce, aceda ao separador 'Módulos'> 'Módulos e Serviços'.</Translate>

<br/>
<br/>

![configuracao1](@site/_media/prestashop/prestashop-2.png)

<Translate id="integrations.prestashop.config.step2">Clique na opção 'Enviar um módulo'.</Translate>

<br/>
<br/>

![configuracao2](@site/_media/prestashop/prestashop-3.png)

<Translate id="integrations.prestashop.config.step3">Será apresentada a seguinte área onde poderá optar por arrastar ou selecionar omódulo a importar. O módulo deverá estar em formato ZIP ou tarball e deverácarregar apenas um de cada vez.</Translate>

<br/>
<br/>

![configuracao3](@site/_media/prestashop/prestashop-4.png)

<Translate id="integrations.prestashop.config.step4">Após o passo anterior o módulo é instalado automaticamente na sua loja. Clique em 'Configurar' para iniciar a sua configuração</Translate>

<br/>
<br/>

![configuracao4](@site/_media/prestashop/prestashop-5.png)

<Translate id="integrations.prestashop.config.step5">No formulário deverá introduzir os dados de acesso ao webservice da PayPay. Para obter estes dados, aceda à PayPay.pt em Configurar > Integrações > Plataformas de Integração > Adicionar (Extensão PrestaShop), e no final, selecione a opção 'Guardar'.</Translate>

<br/>
<br/>

![configuracao5](@site/_media/prestashop/prestashop-24.png)

:::info
<p><Translate id="integrations.prestashop.config.infoMessage">A sua loja agora está apta para gerar e fornecer os dados de pagamento aos seus clientes, em tempo real, de acordo com o método de pagamento escolhido (Multibanco, Cartão de Crédito/Débito e MB WAY).</Translate></p>

<p><Translate id="integrations.prestashop.config.infoMessage2">Caso surja alguma dúvida, não hesite em contactar-nos. Estamos disponíveis para ajudá-lo na configuração.</Translate></p>
:::
