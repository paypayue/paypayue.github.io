In order to execute the integration with PayPay, the merchant:
- Must be registered on the PayPay platform;
- Must install Zen Cart on his/her computer at https://www.zencart.com/downloads.php and download version 1.5.7d;
- Once the installation is completed and the shop is configured, go to the administration area and log in.
