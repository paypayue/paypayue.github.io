# opencart

## [Download](https://www.opencart.com/index.php?route=marketplace/extension/info&extension_id=27224)

## Requirements

In order to execute the integration with PayPay, the merchant:
- Must be registered on the PayPay platform;
- Must install OpenCart on his/her computer at www.opencart.com;
- Must download the files for the OpenCart plugin at https://www.paypay.pt;
- Must configure the information, with the currency ‘Euro’ and the country ‘Portugal’ (your-store- url/admin/index.php) and in Settings > Edit your store > Local;

![requirements1](../../../../../_media/opencart-1.png)

- Must access the shop (your-store-url/index.php). The following preview should be displayed:
